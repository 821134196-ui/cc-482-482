# 小学陶艺教室 · 窑炉排期与烧制批次系统

管理班级、匿名学生作品代号、泥料、釉色、作品尺寸、干燥状态、窑炉、棚板位置、
烧制程序、装窑照片、出窑结果、裂损与补烧的本地演示系统。
纯 Python 标准库实现（`http.server` + `sqlite3` + `unittest`），零第三方依赖。

## 一条命令启动

```bash
python3 run.py            # 默认端口 8000，数据目录 ./data
python3 run.py --port 8080 --data ./data2
```

启动时自动完成：建库建表 → 载入样例数据 → 启动进程内调度任务 → 启动 Web 服务。
打开 http://localhost:8000 ，选择身份登录（本地演示免密码）：

| 账号 | 角色 | 权限 |
| --- | --- | --- |
| `admin` | 管理员 | 全部操作：点火、停电/恢复、异常开窑 |
| `wang` / `li` | 教师 | 作品登记、干燥确认、排期、装窑、正常开窑、出窑清点、补烧 |
| `s01` ~ `s12` | 学生（匿名代号 A01~A12） | 仅查看自己的作品进度与成品照片 |

## 运行测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：排期互斥、装载约束（超高/釉料相冲/容量）、开窑阻断、作品唯一、
权限边界、干燥确认留痕，以及 Web 层冒烟测试。

## 业务流程

1. **作品登记** → 自动进入自然干燥（默认 48h，可调整）。
2. **干燥队列** → 到达要求时长后教师确认合格；提前确认被拒绝并留痕（干燥不足）。
3. **排期** → 教师为窑炉创建批次，同一窑炉时段不能重叠（已点火批次按实际烧制+冷却时段判定）。
4. **装窑** → 按尺寸（层净高）与釉料相容性分配棚板；超高、相冲、容量不足均被拒绝并留痕；
   支持手动指定层位与自动分配。同一作品不能加入两个未结束批次。
5. **程序确认** → 点火前可调整烧制程序（阶梯曲线可视化）；点火（仅管理员）后批次与程序锁定。
6. **烧制监控** → 模拟适配器提供窑温读数（升温/保温/冷却/停电降温），页面每 2 秒刷新。
7. **停电中断** → 管理员上报停电（留痕），恢复后烧制与冷却时点自动顺延。
8. **开窑** → 完全冷却（冷却计时结束）后教师可开窑；未冷却属异常开窑，需管理员并留痕。
9. **出窑清点** → 逐件登记 完好/裂损/少件，裂损与少件自动留痕。
10. **补烧** → 裂损作品创建补烧时必须引用原作品与失败原因，随后可排入新批次，全程追踪。

## 异常留痕

标签脱落、干燥不足、釉料相冲、装载超高、停电中断、恢复供电、异常开窑、
裂损、作品少件 —— 全部记录在 `incidents` 表，集中在「异常留痕」页可查。
样例数据已包含：釉料相冲（窑变橙×翠绿釉）、装载超高（30cm 作品）、干燥不足、
标签脱落、停电中断（二号窑·釉烧·第3批）、裂损补烧（W017）、少件（W018）。

## 技术结构

```
run.py                # 一条启动命令：建库 + 种子 + 调度 + 服务
pottery/
  db.py               # SQLite 表结构（作品全链路）
  domain.py           # 程序时长/温度曲线/冷却/时段重叠 纯计算
  services.py         # 业务规则核心（所有约束与留痕）
  kiln_adapter.py     # 模拟窑温适配器（可替换为真实传感器驱动）
  scheduler.py        # 进程内调度：推进 烧制→冷却→待开窑
  seed.py             # 样例数据（含冲突/停电/补烧样例）
  photos.py           # 样例装窑照/成品照（SVG 占位图）
  web.py              # HTTP 路由、会话、权限
  views.py            # 页面渲染（陶土白/窑火橙/釉蓝，棚板俯视 SVG、阶梯曲线 SVG）
  static/             # style.css / app.js
tests/                # unittest：排期互斥/装载约束/开窑阻断/作品唯一/权限边界/干燥/Web
data/                 # 运行时生成：pottery.db + photos/（装窑与成品照片）
```

- **SQLite** 保存作品链路：登记→干燥→装窑→烧制→出窑→补烧全程可追溯。
- **本地目录** `data/photos/` 存放装窑照片与成品照片（上传为原始字节 POST，免 multipart）。
- **进程内任务** `Scheduler` 每秒推进批次状态；干燥与冷却时点在登记/点火时计算落库。
- **学生端** 只展示作品进度时间线与成品照片，不暴露任何设备控制。

## 界面

- 配色：陶土白底、窑火橙主色、釉蓝辅色。
- 棚板排布：圆形层位俯视 SVG，作品以编号+尺寸小块表示，颜色取自釉色，标签脱落有红框警示。
- 温度程序：清晰阶梯曲线（升温段斜线 + 保温段平台 + 冷却段），烧制中叠加当前温度点。
- 窑炉日历：按周展示两座窑的批次占用，冲突时段无法创建。
